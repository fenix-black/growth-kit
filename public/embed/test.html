🚀 GrowthKit Embed Test

Test page for script tag embedding

⚠️ Testing Instructions: Replace pk_YOUR_PUBLIC_KEY with a real public key from your GrowthKit dashboard. For local testing, use: http://localhost:3000/embed/test.html

1. Waitlist Widget (Standard)

Basic waitlist form embedded via script tag

<script src="/embed/growthkit.js" data-public-key="pk_YOUR_PUBLIC_KEY" data-widget="waitlist" data-theme="auto" async></script>

2. Account Widget (Slim)

Compact account widget showing credits

<script src="/embed/growthkit.js" data-public-key="pk_YOUR_PUBLIC_KEY" data-widget="account" data-slim="true" async></script>

3. Programmatic API

Using the JavaScript API to render widgets

// Initialize with config GrowthKit.init({ publicKey: 'pk_YOUR_PUBLIC_KEY', theme: 'light' }); // Render to specific container GrowthKit.widgets.waitlist.render('#my-container'); // Listen for events GrowthKit.on('waitlist:joined', (data) => { console.log('Joined at position:', data.position); });
